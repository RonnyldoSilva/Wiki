# Data Ingestion and Storage at AWS

- Structured Data:
  - Easily queryable, organized in rowns and columns, has a consistent structure;
  - Exemples: database tables, CSV files with consistent columns, Excel spreadsheets.
 
- Unstructured Data:
  - Definition: Data that doesn't have a predefined struture or schema.
  - Characteristics: Not easily queryable without preprocessing, may came in various format.
  - Examples: text files without a fixed format, videos and audios files, images, emails and word processing documents.

- Semi-Structured Data:
  - Definition: Data that is not as organized as strutured data but has some level of struture in the form of bags, hierarchies, or orther patterns.
  - Characteristics: Elements might be tagged or categorizes in some way. More flexible than strutured data but not as chaotic as unstrutured data.
  - Exemples: XML and JSON files, email headers (which have a mix of strutured fields like date, subject, etc., and unstructured data in the body), log files with varied formats.
